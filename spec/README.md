# Specification Artifacts

This directory contains A2SPA Core Protocol specification artifacts.

## Current Text

- `A2SPA_Core_Protocol_Specification_v0.9.2.md` is the current implementation-aligned review draft.

## Historical Note

The earlier `v0.9.1-clean` Word/PDF draft has been removed from the current repository because it included claims that do not match the public A2SPA implementation, including IETF-style status language, Go/Rust reference implementation language, Ed25519 as a mandatory baseline, RFC 8785 as the current signed-byte baseline, and EEP-generated challenge nonce flow.

Use the Markdown `v0.9.2` draft for current review.

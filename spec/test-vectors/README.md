# Test Vectors

Current cross-language test vectors for the A2SPA `0.1.3` Signed Bytes V1 compatibility profile are not yet published in this repository.

Implementers should use the public helper packages (`a2spa==0.1.3` and `a2spa@0.1.3`) until vectors are published. Planned vectors should cover RSA PKCS#1 v1.5 SHA-256 payload signatures, payload hashes, nonce/timestamp handling, state continuity, receipt verification, and optional ML-DSA where supported.

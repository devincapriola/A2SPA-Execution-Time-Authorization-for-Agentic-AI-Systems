# A2SPA Specification

The canonical, versioned A2SPA Core Protocol Specification is maintained under `spec/`:

- [A2SPA Core Protocol Specification v0.9.2](spec/A2SPA_Core_Protocol_Specification_v0.9.2.md)

This draft is aligned with the public A2SPA app/API and helper packages `0.1.3`. It documents the current RSA PKCS#1 v1.5 SHA-256 payload signature profile, Signed Bytes V1 compatibility profile, optional ML-DSA profile, nonce/timestamp replay controls, state-continuity checks, signed execution receipts, public API aliases, and fail-closed decision handling.
